# Al Monte — Luxury Real Estate Dubai

A modern, single-page real estate website for a Dubai luxury property agency. Built with Next.js 16, featuring smooth scroll animations, cinematic transitions, and an interactive property portfolio.

## About

Al Monte is a high-end real estate platform showcasing luxury properties across Dubai — penthouses, beachfront villas, golf course residences, and more. The site includes a filterable property portfolio, animated stats, tailored solutions accordion, smart ownership diagram, masonry gallery, and consultation/catalog modals.

## Tech Stack

- **Next.js 16** — App Router, React 19, TypeScript
- **Tailwind CSS v4** — utility-first styling
- **GSAP 3** — scroll animations, parallax, counter reveals
- **Framer Motion 14** — entrance animations, layout transitions
- **Lenis** — smooth scroll engine synced with GSAP ScrollTrigger
- **Lucide React** — icons

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Other Commands

```bash
npm run build    # production build
npm run start    # start production server
npm run lint     # run ESLint
```
